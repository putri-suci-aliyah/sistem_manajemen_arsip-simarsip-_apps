# 📁 SIMARSIP – Sistem Manajemen Arsip

SIMARSIP (Sistem Manajemen Arsip) merupakan aplikasi yang dibuat untuk membantu proses pengelolaan arsip secara digital. Aplikasi ini menyediakan fitur untuk melakukan login berdasarkan role pengguna, mengajukan arsip, mengelola data arsip, memproses pengajuan, serta melihat informasi dan status pengajuan.

## 👥 Role Pengguna

SIMARSIP memiliki beberapa role pengguna dengan hak akses yang berbeda.

| Role | Keterangan |
|------|------------|
| **Super Admin** | Mengelola keseluruhan sistem dan data pengguna |
| **Admin SIMARSIP** | Mengelola data dan proses administrasi arsip |
| **BAA** | Memproses dan memverifikasi pengajuan arsip |
| **Organisasi** | Mengajukan dan memantau proses pengajuan arsip |

---

## 🎯 Tujuan Pengembangan

Aplikasi SIMARSIP dikembangkan untuk membantu proses pengelolaan arsip secara digital agar proses pengajuan, pemeriksaan, penyimpanan, dan pemantauan arsip dapat dilakukan secara lebih terstruktur dan mudah diakses oleh pengguna.
